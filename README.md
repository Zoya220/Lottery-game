# 🎟️ React Lottery Ticket Game

A sleek, interactive 3-digit lottery application built with **React**, **Vite**, and custom **CSS3 animations**. Click to draw a new ticket and test your luck to see if your digits sum up to 15!

## ✨ Features

- **🎲 Instant Ticket Generation:** Generates a set of 3 random numbers (1–9) with a single click.
- **🎉 Automatic Win Detection:** Real-time logic that evaluates the digit total and triggers a victory banner when the sum equals 15.
- **✨ Vibrant Glowing UI:** Styled with deep glassmorphism gradients, glowing card elements, and pop-in victory animations.
- **📱 Fully Responsive:** Clean, centered container optimized for both mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Styling:** Custom CSS3 (Flexbox, Linear Gradients, Keyframe Animations)
